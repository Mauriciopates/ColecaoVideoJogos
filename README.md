# Coleção de Videojogos

Aplicação Android para gerir uma coleção pessoal de videojogos, desenvolvida em **Kotlin** com **Jetpack Compose**.

Trabalho prático individual da UFCD 00609 – Desenvolver aplicações móveis (plataforma Android), curso TPSI – IEFP.

## Funcionalidades

- [x] Listar videojogos
- [x] Pesquisar por nome
- [ ] Adicionar videojogos (com validação)
- [ ] Editar videojogos
- [ ] Eliminar videojogos
- [ ] Guardar os dados localmente (Room)

## Dados de cada jogo

Nome · Plataforma · Género · Ano de lançamento · Estado (Por Jogar / A Jogar / Concluído)

## Tecnologias

- Kotlin
- Jetpack Compose (Material 3)
- ViewModel
- Navigation Compose

## Como executar

1. Abrir o projeto no Android Studio
2. Sincronizar o Gradle
3. Executar num emulador ou dispositivo (Android 7.0+ / API 24)
